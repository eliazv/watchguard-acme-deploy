# Security policy

`wgcert` handles private keys and WatchGuard API credentials. Do not put secrets, private keys, access tokens, or unredacted HTTP bodies in public issues.

For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/eliazv/watchguard-acme-deploy/security/advisories/new). For ordinary bugs and sanitized Firebox test results, use the issue templates.

v0.1.0 is an experimental public beta. It has offline unit and mock API coverage but has not yet completed a real Firebox deployment cycle. Test on a disposable device before production use.
