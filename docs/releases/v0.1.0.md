# wgcert v0.1.0 — public beta

This prerelease adds an offline-tested Go CLI for deploying already-issued TLS certificates to cloud-managed WatchGuard Fireboxes.

## Included

- `devices`, `deploy`, and `check` commands with text or JSON output.
- Certificate/key validation, SHA-256 fingerprints, dry-run, and TLS endpoint checks.
- OAuth authentication and WatchGuard certificate create/install requests.
- Opt-in full configuration deployment with transaction polling.
- Certbot and acme.sh hook examples.
- Linux, macOS, and Windows binaries with SHA-256 checksums.

## Validation status

Unit and mock API tests pass. **No real cloud-managed Firebox has been tested end-to-end.** The install command is asynchronous and API inventory does not establish which certificate is active on a service. Test first on a disposable device, verify the served TLS endpoint, and report results through the Firebox test issue template.

`--deploy-config` deploys all pending configuration changes for the device. Review them before using this flag.

See the [Quick Start](https://github.com/eliazv/watchguard-acme-deploy#quick-start) and [validation checklist](https://github.com/eliazv/watchguard-acme-deploy/blob/main/docs/testing.md).
